## Структура проекта

В проекте реализованы 2 алгоритма предобработки.

Основные папки:

- `playground`: замеры характеристик кода и всякие эксперименты с ним
    - `playground/plot`: код, который замеряет характеристики и генерирует csv, использовавшиеся для построения графиков
      в статье и презентации
- `src`: основной код проекта
    - `src/matrix`: код для работы с разреженными матрицами в формате CSC
    - `src/nonzeros`: первый алгоритм предобработки, который уменьшает число ненулевых элементов
    - `src/problems`: код для чтения и хранения задачи СЦЛП
    - `src/splitters`: оба алгоритма предобработки требуют на вход разбиение столбцов на группы, здесь собраны классы,
      которые дают такое разбиение
    - `src/utils`: вспомогательный код
    - `src/vars`: второй алгоритм предобработки, который убирает переменные и ограничения
- `tests`: тесты

## Сборка

При сборке нужно передать аргументом в CMake путь до папки с MIPLIB Benchmark Set. Задачи могут быть в виде архивов (
`.mps.gz`), код автоматически их разархивирует. Эти задачи используются для тестов и замеров характеристик методов.

```shell
cmake -DPROBLEMS_PATH=<путь до MIPLIB> -B build .
```

## Разное

Сейчас алгоритм в `src/vars/Reducer.h` игнорирует целочисленность переменных. Это связано с тем, что если 
$\alpha x_1 = \beta x_2 + \gamma$, где оба $x_1, x_2$ целочисленные, то нельзя просто так подставить $x_1 = (\beta x_2 + \gamma) / \alpha$ в задаче.
